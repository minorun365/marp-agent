02

追加したPythonファイルがコンテナに入っていなかった

利用者識別を記録する変更で、エントリポイントのagent.pyからidentity.pyを読み込むようにした。一方、Dockerfileはコピーするファイルを2本に固定しており、新しいファイルが本番イメージへ入らなかった。

ModuleNotFoundError: No module named 'identity'

本番と同じECRイメージを手元で起動し、エントリポイントのimport時に同じ例外で終了することを確認した。

03

固定リストをやめ、トップレベルのPythonファイルをすべて同梱

今回の1ファイルだけを足す修正ではなく、今後トップレベルへPythonモジュールを追加した場合も自動でコンテナへ入る指定へ変えた。

Before

# エージェントコードと全テーマをコピー
COPY agent.py config.py ./
COPY *.css ./

After

# エージェントコードと全テーマをコピー
# Pythonモジュールの同梱漏れを防ぐ
COPY *.py ./
COPY *.css ./
対象BeforeAfter
コンテナ作成列挙した2ファイルだけコピートップレベルのPythonファイルを一括コピー

障害調査CloudWatchの保存先はあるがログ0件LogsとX-Rayの送信権限を実行ロールへ追加
