# E2Eテストチェックリスト

## テスト環境

| 環境 | URL |
|------|-----|
| sandbox | http://localhost:5173 |
| 本番 | https://pawapo.minoruonda.com/ |

## テストケース

### TC1: 認証
- [ ] サインイン画面が日本語で表示される
- [ ] ログイン/新規登録ができる

### TC2: スライド生成
- [ ] メッセージを入力して送信できる
- [ ] 「標準（Kimi K2.5）」が初期選択されている
- [ ] 「高品質（Claude Sonnet 4.6） ※資金不足により停止中」がグレーアウトされ、選択できない
- [ ] GPT-5.6 Solは表示されない
- [ ] 会話開始後はモデル選択を変更できない
- [ ] ステータス表示が正しく遷移する
- [ ] プレビュータブでスライドが表示される
- [ ] borderテーマが適用されている

### TC3: PDFダウンロード（必須）
- [ ] 「PDFダウンロード」ボタンをクリック
- [ ] PDFがダウンロードされる
- [ ] 日本語が正しく表示される
- [ ] borderテーマが適用されている

**注意**: PDFダウンロードは毎回のテストで必ず実行すること

## 実行コマンド

```bash
# sandbox起動
npm run sandbox

# devサーバー起動（別ターミナル）
npm run dev
```
